# DARKLS

Личная страница проектов: https://iamdarkls.github.io/

Адаптивный статический сайт без npm-зависимостей. Светлая и тёмная темы, поиск и фильтры проектов, подробности, версии и история GitHub Releases.

## Данные релизов

GitHub Actions проверяет `iamdarkls/IPA-Desktop` и `iamdarkls/DARKLS-VPN-Panel` каждый час (на 17-й минуте), после push в main и по ручному запуску. Расписание GitHub может задерживаться; в неактивных публичных репозиториях GitHub может отключить его через 60 дней.

IPA Desktop и device-tools — отдельные каналы. Стабильные и предварительные выпуски разделены. Релизы сортируются по времени публикации, черновики исключаются. Кнопки скачивания указывают на ZIP соответствующего продукта; архивы исходников не выбираются.

Скрипт загружает предыдущий опубликованный снимок как резерв. При ошибке одного репозитория сохраняются его последние успешные данные, второй обновляется независимо. В интерфейсе указаны время проверки (МСК) и задержка, если данные старше трёх часов или проверка завершилась с ошибкой. Обновление не обещает мгновенного появления релиза.

Браузер получает `data/releases.json` со своего сайта при открытии, возвращении на вкладку и каждые пять минут активной вкладки. GitHub API и токен в браузере не используются. При недоступности JSON есть встроенный снимок. Тема сохраняется локально; первоначально учитывается тема устройства. Анимации учитывают `prefers-reduced-motion`.

## Публикация

Settings → Pages → Source: **GitHub Actions**. Единственный workflow: `.github/workflows/site.yml`. Он формирует публичную папку `_site`, загружает артефакт и публикует через GitHub Pages. Записи в main по расписанию нет. Для deploy используются стандартные `pages: write`, `id-token: write`, для сборки — `contents: read`. Сторонние токены не нужны.

## Разработка

- `index.html`, `styles.css`, `app.js` — интерфейс.
- `data/releases.json` — исходный резервный снимок.
- `scripts/update_releases.py` — обновление метаданных.
- `scripts/build_site.py` — подготовка публичных файлов и актуального встроенного снимка.

```sh
python3 -m unittest discover -s scripts -p 'test_*.py'
node --check app.js
python3 scripts/update_releases.py --baseline-url https://iamdarkls.github.io/data/releases.json
python3 scripts/build_site.py
```

Для локального просмотра раздавайте `_site` через HTTP. Python 3.10+, Node.js требуется только для проверки синтаксиса; отдельная установка зависимостей не нужна. Содержимое release notes выводится текстом, не исполняется как HTML. Публикуются только явным образом перечисленные статические файлы.
