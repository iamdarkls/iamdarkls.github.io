# DARKLS

Личная страница проектов: https://iamdarkls.github.io/

Адаптивный статический сайт без npm-зависимостей. Светлая и тёмная темы, поиск и фильтры проектов, подробности, версии и история GitHub Releases.

## Данные релизов

GitHub Actions проверяет `iamdarkls/IPA-Desktop` и `iamdarkls/DARKLS-VPN-Panel` каждый час (на 17-й минуте), после push в main и по ручному запуску. Расписание GitHub может задерживаться; в неактивных публичных репозиториях GitHub может отключить его через 60 дней.

IPA Desktop и device-tools — отдельные каналы. Стабильные и предварительные выпуски разделены. Релизы сортируются по времени публикации, черновики исключаются. Кнопки скачивания указывают на ZIP соответствующего продукта; архивы исходников не выбираются.

Скрипт загружает предыдущий опубликованный снимок как резерв. При ошибке одного репозитория сохраняются его последние успешные данные, второй обновляется независимо. В интерфейсе указаны время проверки (МСК) и задержка, если данные старше трёх часов или проверка завершилась с ошибкой. Обновление не обещает мгновенного появления релиза.

Браузер получает `data/releases.json` со своего сайта при открытии, возвращении на вкладку и каждые пять минут активной вкладки. GitHub API и токен в браузере не используются. При недоступности JSON есть встроенный снимок. Тема сохраняется локально; первоначально учитывается тема устройства. Анимации учитывают `prefers-reduced-motion`.

## Публикация

Settings → Pages → Source: **GitHub Actions**. Единственный workflow: `.github/workflows/site.yml`. Он формирует публичную папку `_site`, загружает артефакт и публикует через GitHub Pages. Записи в main по расписанию нет. Для deploy используются стандартные `pages: write`, `id-token: write`, для сборки — `contents: read`. Сторонние токены не нужны.

## Разработка

- `index.html`, `styles.css`, `app.js` — интерфейс.
- `data/releases.json` — исходный резервный снимок.
- `scripts/update_releases.py` — обновление метаданных.
- `scripts/build_site.py` — подготовка публичных файлов и актуального встроенного снимка.

```sh
python3 -m unittest discover -s scripts -p 'test_*.py'
node --check app.js
python3 scripts/update_releases.py --baseline-url https://iamdarkls.github.io/data/releases.json
python3 scripts/build_site.py
```

Для локального просмотра раздавайте `_site` через HTTP. Python 3.10+, Node.js требуется только для проверки синтаксиса; отдельная установка зависимостей не нужна. Содержимое release notes выводится текстом, не исполняется как HTML. Публикуются только явным образом перечисленные статические файлы.

## Автоматический каталог репозиториев

В том же часовом workflow `scripts/update_repositories.py` получает **все публичные репозитории владельца** через `/users/iamdarkls/repos` с постраничной загрузкой. Авторизация для этого запроса не используется. Приватные и чужие репозитории отбрасываются дополнительно. Каталог обновляется независимо от релизов: названия, описания, основной язык, отметки форков/архива и дата последнего коммита.

Новые публичные репозитории появляются автоматически. При успешной проверке удалённые или ставшие приватными репозитории исчезают из каталога. При сбое любой страницы загрузки сохраняется предыдущий **полный** список и время его успешной проверки; частичный ответ не заменяет каталог. Время проверки и задержка видны под списком. Собственные проекты идут перед форками, внутри группы — сначала недавно изменённые.

Настройка в `projects.json`:

- `owner` — владелец каталога, сейчас `iamdarkls` (смена владельца требует адаптации клиентской проверки ссылок).
- `featured_repositories` — `IPA-Desktop` и `DARKLS-VPN-Panel`; остаются в основных карточках и не дублируются в списке.
- `excluded_repositories` — имена скрываемых проектов. По умолчанию исключён `iamdarkls.github.io`. Чтобы скрыть другой репозиторий, добавьте его точное имя в этот массив. Исключения учитываются и при временном сбое GitHub.

Публичный снимок — `data/repositories.json`. Сборка обновляет HTML-каталог и встроенный снимок, поэтому список доступен без JavaScript и при временной недоступности JSON. Браузер проверяет опубликованный снимок при открытии, возвращении на вкладку и каждые пять минут активной вкладки. Строки GitHub выводятся как текст; серверный HTML экранируется.

```sh
python3 scripts/update_repositories.py --baseline-url https://iamdarkls.github.io/data/repositories.json
```

## Страницы проектов и языки

Русская главная — `/`, английская — `/en/`. Для каждого языка доступны страницы `projects/ipa-desktop/` и `projects/vpn-panel/`. Переключатель RU/EN сохраняет текущий проект. `scripts/site_pages.py` создаёт страницы и sitemap; факты, установка и FAQ редактируются в `content/project_pages.json`. Английский интерфейс браузерного скрипта собирается через `scripts/site_translations.py`. Release notes и описания репозиториев сохраняют исходный язык GitHub.

Лента на главной объединяет 12 последних доступных выпусков IPA Desktop, VPN Panel и device-tools, сортирует по времени публикации и позволяет отфильтровать проект. Она использует тот же часовой снимок релизов. Карточки выпусков и каталога также присутствуют в HTML без JavaScript.

Кнопки обратной связи открывают **черновик** GitHub Issue нужного репозитория с полями для ошибки или идеи; посетитель сам заполняет и отправляет обращение. На сайте нет формы, автоматически отправляющей сообщения.
